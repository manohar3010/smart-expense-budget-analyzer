##OBJECTIVES

##Objective 1

Develop a Python application for recording and managing personal expenses.

##Objective 2

Allow users to categorize expenses and search/filter their transactions.

##Objective 3

Enable users to define monthly and category-wise budgets.

##Objective 4

Analyze spending patterns using Python-based calculations.

##Objective 5

Generate useful expense and budget reports.

##Objective 6

Demonstrate Python programming concepts such as functions, OOP, file handling, exception handling, modules and testing.

##Functional requirements
##FR1 — Expense Management

The system shall allow users to:
Add expenses
View expenses
Update expenses
Delete expenses
Search expenses
Filter expenses

##FR2 — Budget Management

The system shall allow users to:

Set monthly budgets
Set category budgets
View budget usage
View remaining budget
Check budget status

##FR3 — Expense Analytics

The system shall calculate:

Total expenses
Category-wise expenses
Monthly expenses
Average daily expenses
Highest expense
Highest spending category

##FR4 — Spending Insights

The system shall identify:

Budget overspending
High-spending categories
Changes in spending
Budget utilization

##FR5 — Report Generation

The system shall generate:

Monthly expense reports
Category-wise reports
Budget reports

##Non-functional requirements
Performance

The system should process normal student expense records efficiently.

Usability

The command-line interface should provide clear menus and instructions.

Reliability

Invalid input should not terminate the application unexpectedly.

Maintainability

The application should be divided into independent modules.

Error Handling

Invalid amounts, dates, categories and menu choices should be handled appropriately.

Resource Efficiency

The application should use simple file-based storage without unnecessary resource consumption.
